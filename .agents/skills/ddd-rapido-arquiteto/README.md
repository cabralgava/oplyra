# ddd-rapido-arquiteto

Skill para Claude baseada no conteúdo conceitual do arquivo “Domain Driven Design Rapido.pdf”.

## Instalação no Claude Code

Copie a pasta `ddd-rapido-arquiteto` para:

```txt
.claude/skills/ddd-rapido-arquiteto/
```

A estrutura final deve ficar assim:

```txt
.claude/
  skills/
    ddd-rapido-arquiteto/
      SKILL.md
      references/
      templates/
```

## Teste rápido

```txt
/ddd-rapido-arquiteto Modele um CRM imobiliário usando DDD, com leads, oportunidades, tarefas, WhatsApp e transferência para atendimento humano.
```

## Uso recomendado

Use esta skill para:

- modelar domínios complexos;
- criar PRDs orientados por DDD;
- revisar arquitetura e banco;
- criar prompts técnicos para implementação;
- separar domínio de infraestrutura;
- mapear bounded contexts;
- desenhar camada anticorrupção para integrações externas.
```
